# Эксплуатация

## Штатная публикация

1. Проверка Pylint в Pull Request должна завершиться успешно.
2. Выполнить слияние в `main`.
3. Открыть Actions → Publish documentation.
4. Проверить опубликованный сайт.

## Диагностика

Определите, где произошёл сбой:

- Pylint
- сборка MkDocs
- загрузка артефакта
- публикация Pages

## Восстановление

Перед восстановлением изучите [инструкцию по аварийному восстановлению](recovery.md).
