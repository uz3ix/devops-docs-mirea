# Журнал инцидентов

| Инцидент | Симптом | Причина | Исправление |
|---|---|---|---|
| Ошибка Pylint | Красная проверка PR | Неиспользуемая переменная | Удалить переменную |
| Ошибка Pages | Build успешен, deploy падает | Недостаточные права токена | Добавить id-token: write |
| Битая ссылка | MkDocs падает после merge | Файл не существует | Исправить ссылку |
